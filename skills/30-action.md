# 动作与运动

## 写作规则
- 每一拍写清**动作链**：起始姿态 → 动作路径 → 可见结果 → 移交到下一拍的状态。
- 运动写**三要素**：类型（位移/旋转/挥击…）＋幅度（大/中/小）＋速度（快/慢），不要只写"打斗激烈"。
- 写清**主体位移轨迹**与背景的相对运动（背景别跟着人一起动）。
- 快速动作要写"哪一帧最清楚"：说明关键时刻是清晰定格还是允许运动模糊。
- 参考图若提供的是"动作参考"，写清它提供的是**姿态/动作**而不是"开场画面"。

## 评审侧重
- 特别核验：动作是否连贯可读（不是一团糊）、主体身份在运动中是否保持、背景是否穿帮、动作方向是否前后矛盾。
- 长视频（>15 秒）额外核验：**尾部仍有可见运动**，不要前段打完、后段站着。
